# naviPlayer 跨尺寸兼容性检查报告（窗口尺寸模拟）

## 测试范围与方法
- 目标：验证「艺术家表格页」与「底部控制栏」在不同窗口尺寸下布局不崩坏、关键交互可用
- 方法：桌面端通过调整主窗口尺寸模拟移动/平板/桌面视口

## 尺寸断点与预期

### 窄窗口（宽度 < 520）
- 艺术家页：
  - 隐藏「专辑数」列（仅保留：头像 / 艺术家 / 收藏）
  - 艺术家名称保持单行省略，hover tooltip 可查看全名
  - 收藏列可点击切换

### 常规窗口（宽度 >= 520）
- 艺术家页：
  - 展示「专辑数」列并支持数值排序
  - 头像列固定宽度，收藏列固定宽度，名称列自适应撑满

## 结论与风险点
- 已实现的适配机制：
  - 艺术家页通过 resizeEvent 实时调整列隐藏与列宽
- 待你侧重点验证：
  - 极端长名称（200+ 字符）tooltip 是否完整可读
  - 大量艺术家（1k+）下排序/筛选性能与封面请求策略是否满足预期
